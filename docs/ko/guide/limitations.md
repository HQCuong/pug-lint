# 알려진 제한 사항

- **여러 줄 속성 값에는 백틱이 필요합니다.** `'…'`나 `"…"` 값 안의 줄바꿈은 Pug 구문 에러이며(Pug 자체도 컴파일하지
  못합니다), `vue/no-parsing-error`로 보고됩니다. 템플릿에 파싱 에러가 있는 동안에는 그 안에서 어떤 fix도 적용되지
  않습니다.
- **축약 표기는 `vue/*` 규칙에게 속성이 아닙니다.** `.class`와 `#id` 축약 표기는 속성으로 노출되지 않으므로,
  `vue/no-restricted-class` 같은 규칙은 축약 표기로 쓴 class를 보지 못합니다.
- **Vue AST는 HTML 템플릿의 AST와 몇 군데 다르며**, `vue/*` 규칙이 이를 알아챌 수 있습니다. 파이프 텍스트 줄(`| text`)은
  줄마다 별도의 텍스트 노드가 됩니다. 템플릿 루트에 바로 있는 텍스트에는 텍스트 노드가 없습니다. 문자열 속성 값은 그대로
  전달되므로, directive 문자열 안의 이스케이프된 따옴표(`:x="f(\"a\")"`)는 불필요한 Vue 파싱 에러를 일으킬 수 있습니다.
- **따옴표 없는 값과 `${}` 속성 값**(`a(href=url)`, ``a(title=`${x}`)``)은 Vue 바인딩이 아니라 Pug 컴파일 타임
  표현식입니다. 이 값들은 일반 속성 값으로 `vue/*` 규칙에 전달되며, fix guard는 이를 고쳐 쓰는 모든 fix를 버립니다.
- **따옴표로 시작하는 값은 하나의 문자열이어야 합니다.** `a(title="x" + y)`는 유효한 Pug이지만 파싱 에러
  (`vue/no-parsing-error`)로 보고되며, 이는 의도된 동작입니다. `a(title=("x" + y))` 또는 `a(:title="'x' + y")`로
  작성하세요.
- **단독 CR 줄바꿈.** 줄이 단독 `\r`(옛 Mac 방식)로 끝나는 템플릿에서는 `vue-pug/*` 규칙이 문제를 보고하지만 고치지는
  않으며, tokenizer는 파싱 에러를 보고합니다. 파일을 LF 또는 CRLF로 변환하세요.
- **일부 Pug 구문은 파서가 지원하지 않는 것으로 보고하거나** Pug와 다르게 파싱합니다.
  [지원하지 않는 Pug 구문](./unsupported-syntax)을 참고하세요.
- **fix guard 비용과 일부만 적용되는 fix 묶음:** [fix guard](./fix-guard#cost)를 참고하세요.
