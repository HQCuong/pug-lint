# Защита исправлений {#the-fix-guard}

Автоисправление, ломающее шаблон, хуже, чем его отсутствие. В Pug это сделать легко: отступ задаёт
структуру, и перенос одной строки без её дочерних элементов меняет дерево. Поэтому каждое исправление,
затрагивающее шаблон Pug, проверяется до того, как ESLint его применит.

## Что проверяется {#what-is-checked}

Для каждого шаблона Pug исправление применяется, только если после него шаблон по-прежнему разбирается
и его структура не изменилась:

- теги и их вложенность;
- набор классов и id каждого тега и число атрибутов (так что `p(class="a b")` и `p.a.b` равны, а потеря
  класса нет);
- форма текста и интерполяций;
- каждый фрагмент JavaScript, который компилирует Pug (значения атрибутов без кавычек и `${}`,
  `&attributes`, аргументы mixin, код, заголовки управляющих конструкций, `#{}`), с точностью до отступа.

Парсер сообщает о том, что отвергает сам Pug (например, смесь табуляции и пробелов или повторяющийся
атрибут), так что исправление, которое это внесло бы, тоже отбрасывается.

## Как применяются исправления {#how-fixes-are-applied}

1. Каждое исправление проверяется по отдельности.
2. Оставшиеся исправления проверяются ещё раз как общий набор, который применит ESLint.
3. Исправление, не прошедшее проверку, отбрасывается, а его проблема по-прежнему сообщается, чтобы вы
   могли исправить её вручную.

Это касается каждого правила, которое исправляет файлы `.vue`, включая правила `vue/*` и сторонние правила.
Пока в шаблоне есть синтаксическая ошибка Pug, внутри него исправления не применяются.

## Стоимость {#cost}

Защита заново разбирает шаблон для каждого отдельного исправления, поэтому её стоимость растёт как число
исправлений, умноженное на размер шаблона. Обычный шаблон занимает миллисекунды; полностью неотформатированный
шаблон на 3000 строк может занять несколько секунд. Эта стоимость возникает только пока в шаблоне есть
проблемы, которые нужно исправить.

## Частичные наборы исправлений {#partial-fix-sets}

Защита проверяет полный набор оставшихся исправлений. Если ESLint применяет лишь часть из них
(`--fix-type` или собственный предикат `fix` в Node.js API), такое подмножество как набор не проверялось.
