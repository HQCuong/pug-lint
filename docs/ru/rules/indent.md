# vue-pug/indent

Требует единообразных отступов в шаблонах Pug.

✅ Включено в `configs.recommended` (на уровне `warn`). 🔧 Исправляется через `--fix`.

Заменяет `vue/html-indent`, которое падает на шаблонах Pug и отключено в `configs.base`.

## Подробности о правиле {#rule-details}

Правило проверяет ведущие пробельные символы каждой строки в блоке `<template lang="pug">`:

- Строка с тегом, текстом, кодом или управляющей конструкцией имеет отступ в одну единицу на каждый
  уровень вложенности.
- В многострочном блоке атрибутов строки атрибутов на один уровень глубже тега, а строка, начинающаяся
  с закрывающей `)`, находится на уровне тега.
- Строки текстового блока (`p.`, `pre.`, `script.`), комментария, блока кода или фильтра после первой
  сохраняют своё смещение относительно первой строки, так что собственный отступ блока сохраняется при его
  перемещении. Когда символ отступа меняется (пробелы на табуляцию или обратно), строка с отступом меньше,
  чем у первой, не может сохранить смещение: она получает отступ первой строки, поскольку смесь табуляции
  и пробелов является синтаксической ошибкой Pug.
- Строки, которые начинаются внутри строки или шаблонного литерала, никогда не переотступаются: их ведущие
  пробельные символы являются частью значения.
- Строки в области, о которой парсер сообщает как об ошибке, пропускаются.

Отступ в Pug задаёт структуру: перенос одной строки без её соседних и дочерних элементов меняет дерево.
Поэтому каждое сообщение по шаблону несёт одно и то же исправление, которое переотступает весь фрагмент
сразу. Одного оставшегося сообщения достаточно, чтобы исправить все за один проход.

### Неправильно {#incorrect}

```vue
<template lang="pug">
div
   p Hello
</template>
```

```vue
<template lang="pug">
ul
  li(
      v-for="item in items"
    :key="item.id"
  ) {{ item.name }}
</template>
```

### Правильно {#correct}

```vue
<template lang="pug">
div
  p Hello
</template>
```

```vue
<template lang="pug">
ul
  li(
    v-for="item in items"
    :key="item.id"
  ) {{ item.name }}
</template>
```

```vue
<template lang="pug">
div
  pre.
    first line
      keeps its extra indentation
  p(title=`a
      b`)
</template>
```

## Опции {#options}

```js
'vue-pug/indent': ['warn', 2, { baseIndent: 0 }]
```

- Первая опция: единица отступа, число пробелов (по умолчанию `2`) или `'tab'`.
- `baseIndent` (по умолчанию `0`): число единиц, добавляемых к каждой строке, чтобы узлы верхнего уровня
  можно было сдвигать относительно `<template>`.

### Неправильно с `["tab"]` {#incorrect-with-tab}

```vue
<template lang="pug">
div
  p Hello
</template>
```

### Правильно с `["tab"]` {#correct-with-tab}

```vue
<template lang="pug">
div
	p Hello
</template>
```

### Правильно с `[2, { "baseIndent": 1 }]` {#correct-with-2-baseindent-1}

```vue
<template lang="pug">
  div
    p Hello
</template>
```
