# Sicherheitsrichtlinie

> Diese Übersetzung kann hinter der englischen Fassung zurückliegen. Bei Abweichungen ist die [englische Fassung](../../SECURITY.md) maßgeblich.

## Unterstützte Versionen

Nur die jeweils neueste Version von `eslint-plugin-pug-vue` und `pug-lint-parser` erhält Fixes.

## Eine Sicherheitslücke melden

Bitte eröffnen Sie kein öffentliches Issue. Melden Sie sie vertraulich über
[GitHubs privates Melden von Sicherheitslücken](https://github.com/HQCuong/pug-lint/security/advisories/new)
mit einer Beschreibung, der betroffenen Version und Schritten zur Reproduktion.

Sie sollten innerhalb einer Woche eine Antwort erhalten. Sobald ein Fix veröffentlicht ist, wird
das Advisory mit Nennung Ihres Namens veröffentlicht, es sei denn, Sie bleiben lieber anonym.

Beide Pakete laufen innerhalb von ESLint auf Ihren eigenen Quelldateien und stellen keine
Netzwerkanfragen. Ein Fehler, der nur ein falsches Lint-Ergebnis oder einen falschen Fix erzeugt, ist
keine Sicherheitslücke; melden Sie ihn als normales
[Issue](https://github.com/HQCuong/pug-lint/issues/new/choose).
