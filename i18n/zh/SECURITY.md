# 安全策略

> 本译文可能落后于英文版。如有出入，以[英文版](../../SECURITY.md)为准。

## 支持的版本

只有 `eslint-plugin-pug-vue` 和 `pug-lint-parser` 的最新版本会收到修复。

## 报告漏洞

请不要公开提 issue。请通过
[GitHub 的私密漏洞报告](https://github.com/HQCuong/pug-lint/security/advisories/new)
私下报告，并附上问题描述、受影响的版本和复现步骤。

你应当会在一周内收到回复。修复发布后，我们会公开安全公告并署上你的名字，除非你希望保持匿名。

这两个包都在 ESLint 内部处理你自己的源文件，不发起任何网络请求。只会导致错误的 lint 结果或错误修复的 bug 不属于漏洞，请按普通
[issue](https://github.com/HQCuong/pug-lint/issues/new/choose) 报告。
