# Politique de sécurité

> Cette traduction peut être en retard sur la version anglaise. En cas de divergence, la [version anglaise](../../SECURITY.md) fait foi.

## Versions prises en charge

Seule la dernière version d'`eslint-plugin-pug-vue` et de `pug-lint-parser` reçoit des correctifs.

## Signaler une vulnérabilité

Merci de ne pas ouvrir d'issue publique. Signalez-la en privé via le
[signalement privé de vulnérabilités de GitHub](https://github.com/HQCuong/pug-lint/security/advisories/new),
avec une description, la version concernée et les étapes pour reproduire.

Vous devriez recevoir une réponse sous une semaine. Une fois le correctif publié, l'avis est publié
avec mention de votre nom, sauf si vous préférez rester anonyme.

Les deux packages s'exécutent dans ESLint sur vos propres fichiers source et ne font aucune requête
réseau. Un bug qui produit seulement un mauvais résultat de lint ou une mauvaise correction n'est pas
une vulnérabilité ; signalez-le comme une [issue](https://github.com/HQCuong/pug-lint/issues/new/choose) normale.
