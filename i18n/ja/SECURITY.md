# セキュリティポリシー

> この翻訳は英語版より更新が遅れている場合があります。内容に相違がある場合は、[英語版](../../SECURITY.md)が正式なものです。

## サポート対象のバージョン

修正が提供されるのは、`eslint-plugin-pug-vue` と `pug-lint-parser` の最新リリースのみです。

## 脆弱性の報告

公開の issue は作成しないでください。[GitHub の非公開の脆弱性報告](https://github.com/HQCuong/pug-lint/security/advisories/new)から、内容の説明、影響を受けるバージョン、再現手順を添えて、非公開で報告してください。

1 週間以内に返信があるはずです。修正がリリースされると、匿名を希望しない限り、あなたの名前を明記したアドバイザリが公開されます。

どちらのパッケージも、ご自身のソースファイルに対して ESLint の中で動作し、ネットワークリクエストを行いません。誤った lint 結果や誤った fix を出すだけのバグは脆弱性ではありません。通常の [issue](https://github.com/HQCuong/pug-lint/issues/new/choose) として報告してください。
